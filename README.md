# 🧮 Python Calculator

A simple and beginner-friendly calculator written in Python.  
It supports essential arithmetic operations such as addition, subtraction, multiplication, division, and revenue calculation.

This project was created to practice Python basics, functions, user input, and simple program structure.

---

## 🚀 Features

- ➕ Addition  
- ➖ Subtraction  
- ✖️ Multiplication  
- ➗ Division  
- 💰 Revenue calculation (useful for basic finance)
